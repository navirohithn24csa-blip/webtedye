# SD TRENDYZ — Premium Fashion & Product Catalog

A complete, modern, responsive Shorts, Shirts & T-Shirts product catalog website built with React, TypeScript, Tailwind CSS, Vite, and Lucide Icons.

---

## 🌟 Features

* **Non-Ecommerce Product Catalog**:
  * Clean showcase with product pricing in ₹ (INR).
  * No cart, checkout, or online payments.
  * Direct WhatsApp and multi-representative customer enquiry options.

* **Collections Navigation**:
  * 2-column Desktop mega-dropdown & mobile accordion navigation.
  * **Shirts**: Tie & Dye, Acid Wash, Plain, and Printed styles.
  * **T-Shirts**: Tie & Dye, Acid Wash, Plain, and Printed styles.

* **Interactive Product Showcase**:
  * Multi-angle HD image gallery with zoom and lifestyle angles.
  * Interactive color swatches with HEX tooltips.
  * Size availability pills (S, M, L, XL, XXL) & Size Guide Modal.
  * Detailed fabric & garment specifications table.
  * Wash & Care instructions.

* **Production Workflow (About Us)**:
  * 6-stage alternating manufacturing workflow:
    1. Tie & Dye
    2. Acid Wash
    3. Printings
    4. Garments
    5. Quality Checking
    6. Shipping

* **Direct Channels (Contact Us)**:

  * Direct one-click phone dial and WhatsApp chat links.
  * Interactive location map & business working hours.

* **Built-in Admin Control Portal**:
  * Access at `/admin` (Passcode: `admin123`).
  * Manage Products, Categories, Collections, Homepage CMS, Customer Enquiries, and Website Settings.
  * Full JSON Database backup export and import.

## 🛠️ Tech Stack

* **Frontend**: React 18, TypeScript, Vite
* **Styling**: Tailwind CSS, PostCSS
* **Icons**: Lucide React
* **Routing**: React Router DOM v6
* **State Management**: React Context + Persistent LocalStorage

---

## 🚀 Quick Start

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

3. **Build for production**:
   ```bash
   npm run build
   ```
